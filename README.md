# Калькулятор металлурга

Настольное приложение для двух расчётов сталеплавильного производства:

- расход ферросплавов при раскислении и легировании на агрегате ковш-печь (АКОС);
- число ручьёв, глубина лунки, радиус и высота машины непрерывного литья заготовок (МНЛЗ).

Формулы взяты из учебного пособия О. К. Токового «Производство стали и сплавов»: (7.1) и (8.1)–(8.9).

Интерфейс на JavaFX, данные в SQLite. Можно считать вручную, сгенерировать набор записей или загрузить CSV, сохранить журнал и выгрузить его в CSV, XLSX или PDF.

## Запуск

Нужны JDK 21 и Maven 3.9.

macOS и Linux:

```bash
./scripts/run.sh
```

Windows: дважды щёлкните `scripts\run.bat` или из командной строки в корне проекта:

```bat
scripts\run.bat
```

Скрипт проверяет, что стоит JDK 21 или новее, и вызывает Maven через `call`, иначе окно командной строки закрывается сразу после старта. Если запуска не случилось, окно останется открытым и покажет текст ошибки.

Или напрямую:

```bash
mvn javafx:run
```

При первом входе создаётся файл `data/metallurg.db`. Повторный запуск его не затирает.

Демо-доступ: `admin` / `admin`.

## Тесты

```bash
mvn test
```

Проверяются формула расхода ферромарганца (416,7 кг на контрольном примере), параметры МНЛЗ из типовой задачи (один ручей, лунка около 13,2 м) и загрузка окон.

## Сборка архива

```bash
./scripts/build-dist.sh
```

Архив появится в `dist/metallurg-calculator.zip`. Его лучше собирать на той же системе, где будут запускать: JavaFX подтягивает библиотеки под текущую ОС.

## Как устроено

```
src/main/java/com/metallurg/calculator
  ui          окна
  service     расчёт, вход, импорт и экспорт
  dao         запросы к базе
  db          схема и начальные данные
  model       вход и результат расчёта
  util        проверка полей и хеш пароля
```

Пароль в базе хранится как PBKDF2-HMAC-SHA256 с отдельной солью, не открытым текстом.

Примеры файлов для импорта: `samples/`. Схемы классов и расчёта АКОС: `docs/diagrams/`.
