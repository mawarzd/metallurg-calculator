ИС «Калькулятор металлурга» — вариант 4
========================================

1. Расчёт раскисления и легирования на АКОС
-------------------------------------------
Формула расхода ферросплава (Токовой, 7.1):

  Mфер = Mж.ст · ([Э]гот − [Э]исх) · 100 / ([Э]фер · (100 − Куг))

где
  Mж.ст  — масса жидкой стали, кг;
  [Э]гот — содержание элемента в готовой стали, %;
  [Э]исх — содержание элемента до раскисления, %;
  [Э]фер — содержание элемента в ферросплаве, %;
  Куг    — угар элемента, %.

Средние угары на АКОС:
  Al, науглероживатель — 40…50 %
  Si — 15 %
  Mn, Cr — 10…15 %
  Ni, Mo — ≈ 0 %

После легирования при необходимости выполняется науглероживание.

2. Расчёт основных параметров МНЛЗ
----------------------------------
Число ручьев (8.2):

  n = M / (B · b · ρ · v · τmax)

Массовая скорость заготовки (8.3):

  Gз = B · b · ρ · v

Глубина лунки жидкой фазы (8.4)/(8.5):

  Lл = kз · b² · v
  Lл = (kз · b · M) / (0,9 · n · B · τр · ρ)

Радиус/высота радиальной МНЛЗ (8.7):

  R = H = 2 · Lл / π

Практический минимум радиуса (8.9): R ≥ 42 · b

ρ = 7300 кг/м³
kз: 340 (сляб B>1,2 м), 290 (сляб B≤1,2 м), 240 (сортовая)

3. Режимы ввода
---------------
• Вручную — форма на вкладках АКОС / МНЛЗ
• Генерация — случайные наборы заданного количества N
• Из файла — CSV (см. samples/)

4. Операции с данными
---------------------
Чтение, ввод, поиск, сортировка, удаление, импорт, экспорт
(CSV / XLSX / PDF), генерация отчётов, фильтрация — вкладка «Журнал»
и меню «Файл».

5. Безопасность
---------------
Регистрация и вход. Пароли хранятся как PBKDF2-HMAC-SHA256 + соль.
